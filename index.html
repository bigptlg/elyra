Instalação

Carrega primeiro a biblioteca e depois o ficheiro de dados com os ícones. Recomenda-se colocar os scripts antes do fechamento do </body>. 

<script src="https://cdn.pedrodeoliveira.me/icons/elyra.js"></script>
<script src="https://cdn.pedrodeoliveira.me/icons/elyra-data.js"></script>
Sem build obrigatório Carregamento simples Compatível com currentColor

A ordem importa: elyra.js precisa de existir antes de elyra-data.js registar os ícones.

Uso básico

Basta colocar um elemento com data-elyra-icon. A Elyra substitui-o por um SVG inline.

HTML

<i data-elyra-icon="search"></i>
<i data-elyra-icon="user" data-elyra-size="32"></i>
<i data-elyra-icon="heart" data-elyra-stroke-width="1.5"></i>
<i data-elyra-icon="bell" data-elyra-color="#ef4444"></i>

Atributos

Atributo Descrição Exemplo
data-elyra-icon Nome do ícone. Aceita variações como arrowLeft, arrow_left ou Arrow Left. data-elyra-icon="search"
data-elyra-size Define largura e altura do SVG em pixels. data-elyra-size="32"
data-elyra-stroke-width Ajusta a espessura do traço, quando aplicável. data-elyra-stroke-width="1.5"
data-elyra-color Aplica cor via CSS inline. Funciona com ícones que usam currentColor. data-elyra-color="#6366f1"
class As classes do elemento original são preservadas no SVG final. class="text-red"

API JavaScript

A Elyra expõe um objeto global window.Elyra para registo manual, renderização dinâmica e configuração. 

// Renderizar ícones existentes ou adicionados dinamicamente
Elyra.createIcons();

// Renderizar apenas dentro de um contentor
Elyra.createIcons({ root: document.querySelector('#app') });

// Registar ícones manualmente
Elyra.register({
  'my-icon': '<svg viewBox="0 0 24 24"><circle cx="12" cy="12" r="8" /></svg>'
});

// Verificar se um ícone existe
Elyra.has('search'); // true

// Listar nomes disponíveis
Elyra.list(); // ['a-arrow-down', 'activity', ...]

// Configuração global
Elyra.configure({
  defaultSize: 24,
  autoInit: true,
  observe: true
});

Nesta documentação, a inicialização automática é controlada manualmente para permitir renderização lazy da galeria.
